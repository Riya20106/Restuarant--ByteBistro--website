# ByteBistro

ByteBistro is a restaurant website project currently focused on backend development.

## Tech Stack

* Python
* FastAPI
* PostgreSQL
* 
## Running the Project

1. Activate the virtual environment
2. Start the server:

   uvicorn main2:app --port 8001 --reload

3. Access API docs at:

   ```
   http://127.0.0.1:8001/docs
   ```
* APIs can be tested via Swagger UI at `/docs`
* Frontend is currently in progress and will be added soon
